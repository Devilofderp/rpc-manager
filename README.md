# RPC Manager

A Windows tray app for Discord Rich Presence. Keep several custom activities live at once, drag them into the order you want, and show what you're watching in your browser.

## Install

Download the latest `RPC-Manager-Setup` file from [Releases](../../releases/latest) and open it. You need a Discord app on your PC, not Discord in a browser. Modded clients work too, and RPC Manager says if one needs a setting turned on. Updates install themselves.

## Build

```
npm install
npm start
npm run dist
```

`npm run dist` writes the installer to `dist/`.
